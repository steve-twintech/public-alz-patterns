# public-alz-patterns

Public Repo of Patterns and Designs used in Enterprise Scale Azure Landing Zones

## Contents

### Copilot Instructions

AI assistant instructions for different repository types within an Azure Landing Zone architecture.

| Pattern | Description |
|---------|-------------|
| [Workload Repository](copilot-instructions/workload-repo/) | Instructions for bootstrapped workload solution repositories with scoped RBAC, DRY configuration, and central platform integration |

## Overview

This repository contains sample patterns and starters for Azure Landing Zone development, including:

- **Copilot Instructions**: Guide AI assistants to generate compliant code
- **Architecture Patterns**: Reference architectures for common scenarios
- **Terraform Patterns**: Reusable infrastructure-as-code templates
